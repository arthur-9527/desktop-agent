第一阶段收集信息分析指令阶段。第二阶段执行阶段。

分析阶段应该改为。
1.获取无障碍树，深度10层，获取当前系统是windows/linux/mac ,获取当前系统的物理分辨率。
2.整理无障碍树信息，保留系统托盘、任务栏、Program Manager 全部数据。对[windows]部分进行裁剪，仅保留有实际意义的分支 比如有坐标，有说明的部分。/home/test/deskagent/Accessibility.md
3. 获取远程主机系统截图，传入系统信息，传入裁剪后的无障碍树信息，传入截图，传入用户输入。
做以下几个分析：
1. 当前桌面有几个主窗口，每个窗口是什么程序，每个主窗口有几个子窗口。当前桌面聚焦在哪个窗口。
2. 任务栏有哪些图标，作用是什么
3. 系统托盘有哪些图标，作用是什么
4. 桌面有哪些图标。
5. 当前系统输入法是中文还是英文的，是否已联网、音量大小、有无通知、日期时间。
6. 根据输入信息分析，当前系统应该拆解步骤。能使用通用快捷键尽量使用常用快捷键。不能使用常用快捷键则最好使用鼠标操作。

阶段一均使用通用模型，通用模型也支持图片输入。

第二阶段根据上述的拆解流程逐步执行计划：
执行流程为：
1. action->截图->给视觉模型分析-> 是否完成
2. 完成-> 截图给通用模型再确认->确认完成->退出
3. 未完成->给出下一步执行步骤->action

阶段二在操作过程中有几个注意的地方
1. 能用常用快捷键尽量使用常用快捷键操作。不能使用常用快捷键则最好使用鼠标操作。
2. 当截图无法判断，可以使用Accessibility辅助判断。
3. 若需要操作某窗口内部鼠标操作，可以使用带网格的截图用于定位坐标。
